# 🐗 ООО «КАБАН БЛЯЯЯЯЯ»

Браузерная игра про кабана, который торгует чипсами в ларьке.

**▶️ Играть: https://wrt1fc.github.io/kaban-chips/**

Один файл, никаких зависимостей и сборки — можно просто скачать `index.html` и открыть в браузере.

## Как играть

- К прилавку подходят клиенты со своими заказами. Кликай пачки на полке, собери **ровно** заказ и жми **ВЫДАТЬ**.
- Клиент суёт купюру — со 2-й смены надо **отсчитать сдачу** купюрами. Точно до рубля — жирные чаевые.
- Ошибся, недодал сдачи или клиент устал ждать — минус **нервы**. Кончились — кабан ушёл в запой.
- Раз за смену случается **🔥 НАПЛЫВ**: 10 секунд толпы, очередь на четверых и двойной ценник.
- В конце смены платится **аренда** — она растёт каждый день. Не хватило в кассе — ООО ликвидировали.
- Между сменами тратим выручку на апгрейды: ценник, телик в очереди, банка для чаевых, баннер у трассы, пивас, продлёнка.

Рекорд сохраняется в браузере (localStorage).

## Управление

| Клавиша | Действие |
|---|---|
| `1`–`6` | взять пачку с полки / купюру из кассы |
| `Q` `W` `E` `R` | выбрать клиента |
| `Enter` | выдать товар / отдать сдачу |
| `Backspace` | убрать последнее |
| `Delete` | смести всё |
| `M` | музыка вкл/выкл |

Мышь и тач работают везде — клавиатура просто быстрее.
